## Проверка заявлений разработчика

### Баг: SSO-логин не переводит на `/chat`

**Проверка кода:**
- `LoginView.vue:1-13`: теперь вызывает `auth.login()` из Pinia-стора (не прямой IPC)
- `SettingsView.vue:34-36`: после `auth.logout()` выполняет `router.push('/login')`

**Тесты:**
- `login-navigation.test.ts:22-34`: 3 сценария с настоящим `createRouter` + `installAuthGuard` + Pinia + SFC

**Вердикт:** ✅ **Исправлено полностью** — единый путь через стор, гвард видит актуальное состояние
