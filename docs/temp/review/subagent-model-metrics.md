## 3. Практические выводы

1. **Ревью-пары для будущих циклов**: DeepSeek-Flash (полный охват) + GLM-Flash (качество суждений) — ядро; Mercury — третий «свежий взгляд» на поздних фазах; MiniMax — только на research/не-ревью задачи.
2. **M2.7 не ставить на ревью** (подтверждение слов владельца); M3 — можно, но с ретраем на провайдере.
3. Кросс-чек — обязательная фаза: именно он отделил реальные находки от стайл-шума MiniMax (24 валидных против ~8 отклонённых).
4. Итемпо-эффект: находки «второго порядка» (дефекты моих фиксов) давали только DeepSeek и Mercury — ценность свежего прохода после правок.
