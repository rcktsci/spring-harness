# desktop-artifacts Specification

## Purpose
Скачивание и открытие файлов серверного workspace сессии в Web Desktop (`GET /api/v1/sessions/{id}/workspace/files`, api-contracts §8): ввод пути, save-as, open-in-OS. Каталог-листинг отсутствует на сервере — браузер файлов не входит в M5.

## Requirements

### Requirement: Ввод пути и скачивание

UI SHALL предоставлять поле ввода относительного пути файла (подсказка: путь из chat/tool-результатов или ручной ввод) и кнопку «Скачать» (save-as диалог ОС) / «Открыть». Клиент SHALL предварительно проверять путь (UX, не безопасность — серверный гвард D-72 достаточен): абсолютный путь или содержащий `..` → немедленное сообщение «путь должен быть относительным внутри workspace» без запроса. Серверные отказы показываются понятными сообщениями: 404 `session-not-found`/`file-not-found`, 422 `path-invalid`/`extension-not-allowed`, 413 `payload-too-large`.

#### Scenario: скачивание по введённому пути

- **WHEN** пользователь вводит `reports/final.md` и нажимает «Скачать»
- **THEN** файл скачивается стримом в выбранное место

#### Scenario: путь с эскейпом

- **WHEN** пользователь вводит `../../etc/passwd`
- **THEN** показывается UX-сообщение, запрос на сервер не отправляется

#### Scenario: бинарник не разрешён

- **WHEN** сервер отвечает 422 `extension-not-allowed`
- **THEN** показывается сообщение «этот тип файла нельзя скачать/открыть»

### Requirement: Открытие в ОС

Пользователь SHALL открывать файл в приложении ОС по умолчанию: временная копия в `userData/cache/` с именем `<hash(path)>-<basename>` (коллизии исключены хэшем пути); кэш чистится при выходе.

#### Scenario: открыть в ОС

- **WHEN** пользователь нажимает «Открыть»
- **THEN** файл копируется во временный каталог и открывается приложением по умолчанию

### Requirement: Кликабельные пути в ленте

TOOL_RESULT с файловыми путями в output SHALL рендериться с кликабельными ссылками на артефакты (path распознаётся по эвристике — конфигурируемых префиксов/паттернов; клик открывает вкладку артефактов с предзаполненным путём).

#### Scenario: клик по пути

- **WHEN** пользователь кликает путь в результате инструмента
- **THEN** открывается вкладка артефактов с предзаполненным путём
