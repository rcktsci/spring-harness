- [x] O.1 `agent/SubagentSpawner` (`execution/impl/`) — `spawn(agentKey, prompt, params)` строго синхронный (блокирующий): создаёт child session с `parent_session_id = current.id`, `depth = parent.depth + 1` (колонка `session.depth`, миграция 017 / D-61); проверка `depth ≤ harness.spawn.max-depth` ДО создания (`TOOL_RESULT forbidden (depth-limit)` если превышен); запуск child Turn; родительский поток ждёт завершения субагента. Owner = current.owner. Конфиги `harness.spawn.max-depth` + `harness.spawn.workspace-strategy: inherit|new` (M3 — только inherit; new — точка эволюции). Verify: integration — happy path + depth-limit + no-metaTools-гейт (SubagentSpawnTest, 3 теста).
- [x] O.2 Subagent-to-parent финал: блокирующий возврат — `TOOL_RESULT` (с output субагента) фиксируется на ходу родителя, где spawn вызван (движок журналирует обычным порядком; опоздание невозможно, пока Turn жив — поток блокирован в spawn; рестарт = restart-скан LOST). Маппинг исхода: COMPLETED → OK (финальный ASSISTANT), CANCELLED → CANCELLED, FAILED → ERROR; таймаут `harness.spawn.timeout-ms` (дефолт 30 мин) → ERROR spawn-timeout. Verify: integration — orchestrator spawn'ит, субагент работает, родитель получает output.
- [x] O.3 `agent/SubtreeCanceller` (`execution/impl/`) — `POST /api/v1/sessions/{id}/stop` каскадирует по `parent_session_id` (BFS, рекурсивно; врезка в `TurnManagerImpl.requestStop`). Каждой сессии — `cancel_requested=true`; активные Turn'ы завершаются `CANCELLED`; незакрытые async (parked) — синтетический `TOOL_RESULT CANCELLED «subtree-cancelled»` (SubtreeCanceller, под локом sess-{id}, D-64). Stop идемпотентен. Verify: integration — stop в активных Turn'ах → все 3 уровня CANCELLED; parked-ветка canceller'а; повторный stop → 202 без эффекта (SubtreeCancelApiTest, 2 теста).
- [x] O.4 `agent/ReadCompactedTool` (`execution/impl/`) — `read_compacted(compact_message_id)` резолвит `id → (session_id, seq)` по `session_message.id` только в пределах текущей сессии (id чужой сессии → `TOOL_RESULT not-found (no-such-message)`; cross-session-чтение — вне M3, R8). Verify: integration — компактированные сообщения возвращаются; лимит работает; чужой/неизвестный/непокрытый id → not-found (ReadCompactedToolTest, 3 теста).
